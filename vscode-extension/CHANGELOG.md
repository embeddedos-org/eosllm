# Changelog

## [0.1.0] — initial release

- Activity-bar chat webview that streams tokens from `eosllm-cli`.
- Settings: `eosllm.modelPath`, `eosllm.maxTokens`, `eosllm.binDir`.
- Commands: `eosllm.runPrompt`, `eosllm.openChat`.
- Status-bar token-rate readout.
- First-launch postinstall fetches the platform-matching engine
  binary from the engine's GitHub Releases page.
